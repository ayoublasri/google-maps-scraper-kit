# Beauty / hair salon lead-gen — Rabat & Témara (Morocco).
# French terms: that's what these businesses list under on Google Maps in Morocco.
# Best run as TWO jobs (one per city) so each is geo-anchored on its own center
# (Rabat 34.0209,-6.8416 · Témara 33.9266,-6.9062 — ~12 km apart, radius is 10 km):
#
#   python3 scripts/scrape.py "salon de coiffure Rabat" 34.0209 -6.8416 \
#     --keyword "salon de beauté Rabat" --keyword "institut de beauté Rabat" \
#     --depth 5 --max-time 900 --socials --out rabat.csv
#
#   python3 scripts/scrape.py "salon de coiffure Témara" 33.9266 -6.9062 \
#     --keyword "salon de beauté Témara" --keyword "institut de beauté Témara" \
#     --depth 5 --max-time 900 --socials --out temara.csv
#
# Then merge both runs into one deduped, city-tagged lead list:
#
#   python3 scripts/merge_leads.py rabat.csv temara.csv -o beauty-salon-leads.csv
#
# NOTE — where to run this: the scraper needs real egress to Google (www.google.com)
# and, on first start, the Playwright CDNs (playwright.azureedge.net). Email/--socials
# additionally visit each business's own website (arbitrary domains). A normal local
# machine works out of the box; a sandboxed cloud session only works if its network
# policy allows those domains (effectively: unrestricted egress).
#
